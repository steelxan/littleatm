# Little ATM

A simple ATM simulation written in Python.

## Features
- PIN check with 3 attempts
- Check balance
- Withdraw and deposit
- Input validation

## How to run
```
python littleatm.py
```

## Example output
```
Enter password: 1234
Login successfully
1 - Balance
2 - Withdraw
3 - Deposit
4 - Exit
Selection: 2
Enter amount to withdraw: 300
Withdrawn: 300
New balance: 700
```
